# Minimum Viable Product (MVP)

## Goal

Build a functional backend-first Business Operating System within 30 days.

---

## MVP Features

### Authentication

- Login
- Registration
- JWT Authentication

---

### Organization

- Create Organization
- Update Organization

---

### Employee Management

- Add Employee
- Update Employee
- Delete Employee
- View Employees

---

### Project Management

- Create Project
- Assign Employees
- Update Status

---

### Task Management

- Create Task
- Assign Task
- Update Task Status

---

### Dashboard

- Project Summary
- Employee Summary
- Task Summary

---

### MATE Intelligence

- Company Memory
- Business Health Score
- Workload Analyzer
- Daily Briefing
- Decision Simulator (Basic)
